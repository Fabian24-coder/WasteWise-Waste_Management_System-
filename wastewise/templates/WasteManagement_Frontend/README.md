# CleanCity Waste Management Frontend

Based on the supplied Waste Management System ERD.

Pages: login, register, dashboard, profile, pickup requests, payments, rubbish details, collectors, notifications and logout.

The prototype uses LocalStorage for demo CRUD behavior. Connect the forms to Django views or Django REST Framework for production. Implement real password hashing/session authentication, CSRF protection, server-side validation and user ownership/authorization.

The supplied ERD shows Users/User Profile, Pickup Requests, Payments, Rubbish Details and Collectors Details; this frontend keeps those names and fields as the core model.
